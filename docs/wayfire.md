# Wayfire

## Keybindings

### Applications

| Keys | Action |
|------|---|
| Super + D | Open launcher (fuzzel) |
| Super + Return | Open terminal (footclient) |
| Super + F | Open file manager (Thunar) |
| Super + W | Open web browser (Firefox) |
| Super + M | Open Telegram |
| Super + C | Open VSCode |
| Super + Z | Open Zed |
| Super + V | Open Neovim |

### Workspaces

| Keys | Action |
|------|---|
| Super | Show an overview of all workspaces |
| Super + Ctrl + Arrow | Switches to workspace down with the specified activator |
| Super + 1..9 | Switch to a workspace |
| Super + Shift + 1..9 | Send the focused window to workspace N (vswitch) |
| Super + Ctrl + Arrow | Move the focused window with the same key-bindings |

### Windows

| Keys | Action |
|------|---|
| Super + Shift + F | Toogle full screen |
